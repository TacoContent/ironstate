# async

The `async` handler runs tasks asynchronously.

## Fields

| Field | Required | Default | Description |
| --- | --- | --- | --- |
| `poll` | no | - | Polling interval. |
| `async` | no | - | Async timeout/value. |
| `state` | no | `present` | `present` / `absent` / `latest` |
